# tgbot — SMM-service Telegram Bot

A Telegram bot for an SMM/SMO service: order processing, delayed posts and payment postbacks.

## Stack
- Python · SQL database (`database.sql`)
- Modules: `tgbot.py` (bot), `postback.py` (payment callbacks), `delayed_posts.py` (scheduling), `_smoservice_services.py` (service catalog)

## Configuration
Copy `data.ini.py` and fill in your credentials before running.
